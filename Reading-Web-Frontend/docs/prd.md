# Reading-Web-Frontend 学生阅读前端网站
## 1. 概述
### 定位
面向初一学生的纯阅读前端站点，**只读应用**，仅通过Supabase anon密钥读取articles表，无数据库写入权限；收藏功能保存在浏览器localStorage。
### 依赖
Supabase anon只读API
### 目标
干净、低干扰的双语泛读页面；支持视图切换、段落联动高亮、日历查阅、多维度筛选。

## 2. 功能需求
### 2.1 日历导航组件
- 日历组件支持【收起 / 展开】，默认收起，不干扰阅读主视图
- 选择日期，加载当日发布、is_published=true 的文章列表
- 只展示有文章的日期标记

### 2.2 筛选面板
- 筛选面板支持【收起 / 展开】
- 筛选项：主题、文体、难度L1/L2/L3，支持多选过滤
- 文章卡片展示彩色标签，标签颜色取自color_tag字段

### 2.3 文章列表卡片
卡片信息：英文标题、中文标题、主题标签、难度标签、文体标签、发布日期

### 2.4 阅读详情页（核心交互）
1. 排版固定一套布局，不切换左右/上下对照版式
2. 视图切换按钮三档：【仅英文】｜【仅中文】｜【双语同显】
3. 段落绑定：english_paras、chinese_paras按数组下标一一配对
4. 联动高亮：鼠标选中一侧段落文本，自动高亮绑定的另一侧对应段落
5. 无内置生词标注、无点击查词弹窗
6. 无练习题、无解析、无思考题

### 2.5 收藏功能
- 收藏状态存储在浏览器 localStorage，不上传云端
- 独立收藏页面：展示所有收藏文章，支持取消收藏
- 换浏览器、清空缓存后收藏数据丢失

### 2.6 响应式适配
同时适配电脑端、手机端浏览。

## 3. 输入输出
- 输入：从Supabase articles拉取已发布文章数据
- 输出：页面渲染；收藏标记保存在前端本地存储

## 4. 非功能需求
1. 轻量化，加载速度优先
2. 只读，前端代码不包含任何数据库写入逻辑
3. 界面简洁，减少视觉干扰，适合长时间阅读
4. 配色统一，标签颜色与后台配置一致

## 5. 边界说明（不做）
- ❌ 不调用搜索、爬虫、素材采集能力
- ❌ 无法访问 source_log 素材表
- ❌ 没有后台录入、素材管理页面
- ❌ 不做打卡、阅读时长、阅读记录云端存储
