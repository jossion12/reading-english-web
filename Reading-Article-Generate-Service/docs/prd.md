# Reading-Article-Generate-Service 语篇生成服务
## 1. 概述
### 定位
后端生成服务，接收素材梗概与文章参数，调用LLM生成符合规范的中英双语阅读短文，结构化处理后写入Supabase `articles` 表。
### 依赖组件
LLM大模型、Supabase `articles` 表、Supabase `source_log` 表
### 目标
将一条标准化素材梗概，转换为段落一一对应、分级、带标签的双语泛读文本；支持无新闻素材时生成常青科普文章。

## 2. 功能需求
### 2.1 参数接收
接口入参：
- source_id：素材id（关联source_log，常青素材可为null）
- summary：标准化素材梗概文本
- level：难度 L1 / L2 / L3
- style：文体（记叙文 / 说明文 / 应用文 / 议论文）
- theme：主题大类
- sub_theme：子话题
- color_tag：标签色值
- publish_date：发布日期
- sort：同日期文章排序序号
- is_published：是否上线

### 2.2 LLM生成逻辑
- 内置固定扩写Prompt模板，严格约束词数、句式、输出格式
  - L1：80–120词，短句为主，极少从句
  - L2：120–180词，少量定语/状语从句，对标中考B篇
  - L3：180–240词，复合句增多，对标中考C/D篇
- 词数口径：按中考计数 —— 字母词算一个词，连字符/撇号连接的不拆（well-known 算一个），
  **数字也算一个词**（2026、10,000 各算一个）。自检计数与前端展示的「约 N 词」必须同口径，
  否则带年份的稿件会在自检里显示达标、实际却超出难度区间
- 强制要求英文段落数组和中文译文段落数组数量一一对应，用于前端联动高亮
- 禁止在正文输出习题、生词注释、思考题
- **地道英语硬规则（P0 语言质量修复）**：正文要像母语记者为青少年写的原创英文，
  母语读者不能看出是中文回译。禁止中文公文逐字直译（"new era civilization
  practice" / "empower..." / "The reporter learned from..."）、同义反复、直接对读者
  说教（"This tells Grade 7 students to..."）、以及「市+区+街道+社区」四级拼音堆叠。
  地名首次出现只保留最具体一级，难读的拼音名改用泛称（"a small town in Xinjiang"）。
  词数不足时宁可短于区间，也不得靠「换个角度复述同一事实」凑词
- **正向导向不进正文**：梗概里的「正向导向」是写给初一学生的教育评论，解析时单独
  拆出，不进事实清单、不参加逐段派活；模型把它输出成 `reflection_en` /
  `reflection_cn` 两句，供阅读页「读后思考」折叠区展示
- 末段用「背景意义」产出自然的新闻结尾，不能是教育评论

### 2.3 结果自检校验（LLM二次校验）
校验项：
1. 英文词数符合当前难度区间
2. 没有梗概以外编造的事实信息
3. 段落数量英文、中文一致
4. 无敏感、负面内容
5. 中文段落无残留英文单词（≥3 个字母的拉丁串即判不合格）
6. `natural_english`：是否地道英文（中式英语 / 回译腔 / 公文直译 / 地名堆叠 /
   母语作者不会写出的搭配），只报能引用原句的具体问题
7. `no_repetition`：是否有一句几乎原样重复了前句且没有新信息，只报可引用的那句

判官输出新增 `natural_english` / `repetition_free` 两个布尔位；缺省视为通过，
兼容旧日志。判官 temperature 保持 0.2（语言判断比事实判断更吃采样稳定性）。

校验不通过时回喂给模型重写，回喂文案必须**点名具体问题**（哪一段、哪个词），
只给通用规则（如「用中文写」）模型改不动 —— 素材里的英文缩写会被原样照抄，一轮轮不改。
语言项有专门的改写指令：报中式英语时要求「用母语记者的平实英文重写被引句」，
报同义反复时要求「整句删掉被引句」，且不得用另一句复述替换。

### 2.4 结构化解析
解析LLM返回内容，拆分为结构化字段：
- title_en 英文标题
- title_cn 中文标题
- english_paras 英文段落数组 jsonb
- chinese_paras 中文段落数组 jsonb
- reflection_en / reflection_cn 读后思考（各一句，可空；常青文章与存量草稿为空）
- theme / sub_theme / style / level / color_tag

### 2.5 预览与入库流程
1. 先返回预览接口，管理员人工核对内容
2. 确认无误后，写入Supabase articles表，关联source_id
   （`reflection_en` / `reflection_cn` 为空时不写这两列，兼容未应用迁移的旧库）
3. 支持常青素材模式：不依赖新闻梗概，直接按主题+难度生成非时效性科普短文

### 2.6 日志记录
保存生成日志：入参梗概、LLM原始返回内容、入库状态、生成时间

## 3. 输入输出
- 输入：素材梗概、难度、文体、主题标签、发布参数
- 输出：结构化双语文章数据，持久化存入articles表

## 4. 非功能需求
1. 内网访问，不对外暴露公网
2. Prompt模板可配置，方便迭代调整规则
3. 生成失败返回明确错误信息（词数不达标、段落不匹配等）
4. 无并发高负载要求，自用低频使用

## 5. 边界说明（不做）
- ❌ 不搜索新闻、不调用爬虫
- ❌ 不负责素材查重（查重由采集服务完成）
- ❌ 不提供阅读页面、素材管理页面
