# Reading-Article-Generate-Service 语篇生成服务
## 1. 概述
### 定位
后端生成服务，接收素材梗概与文章参数，调用LLM生成符合规范的中英双语阅读短文，结构化处理后写入Supabase `articles` 表。
### 依赖组件
LLM大模型、Supabase `articles` 表、Supabase `source_log` 表
### 目标
将一条标准化素材梗概，转换为段落一一对应、分级、带标签的双语泛读文本；支持无新闻素材时生成常青科普文章。

## 2. 功能需求
### 2.1 参数接收
接口入参：
- source_id：素材id（关联source_log，常青素材可为null）
- summary：标准化素材梗概文本
- level：难度 L1 / L2 / L3
- style：文体（记叙文 / 说明文 / 应用文 / 议论文）
- theme：主题大类
- sub_theme：子话题
- color_tag：标签色值
- publish_date：发布日期
- sort：同日期文章排序序号
- is_published：是否上线

### 2.2 LLM生成逻辑
- 内置固定扩写Prompt模板，严格约束词数、句式、输出格式
  - L1：80–120词，短句为主，极少从句
  - L2：120–180词，少量定语/状语从句，对标中考B篇
  - L3：180–240词，复合句增多，对标中考C/D篇
- 强制要求英文段落数组和中文译文段落数组数量一一对应，用于前端联动高亮
- 禁止输出习题、生词注释、思考题

### 2.3 结果自检校验（LLM二次校验）
校验项：
1. 英文词数符合当前难度区间
2. 没有梗概以外编造的事实信息
3. 段落数量英文、中文一致
4. 无敏感、负面内容

### 2.4 结构化解析
解析LLM返回内容，拆分为结构化字段：
- title_en 英文标题
- title_cn 中文标题
- english_paras 英文段落数组 jsonb
- chinese_paras 中文段落数组 jsonb
- theme / sub_theme / style / level / color_tag

### 2.5 预览与入库流程
1. 先返回预览接口，管理员人工核对内容
2. 确认无误后，写入Supabase articles表，关联source_id
3. 支持常青素材模式：不依赖新闻梗概，直接按主题+难度生成非时效性科普短文

### 2.6 日志记录
保存生成日志：入参梗概、LLM原始返回内容、入库状态、生成时间

## 3. 输入输出
- 输入：素材梗概、难度、文体、主题标签、发布参数
- 输出：结构化双语文章数据，持久化存入articles表

## 4. 非功能需求
1. 内网访问，不对外暴露公网
2. Prompt模板可配置，方便迭代调整规则
3. 生成失败返回明确错误信息（词数不达标、段落不匹配等）
4. 无并发高负载要求，自用低频使用

## 5. 边界说明（不做）
- ❌ 不搜索新闻、不调用爬虫
- ❌ 不负责素材查重（查重由采集服务完成）
- ❌ 不提供阅读页面、素材管理页面
